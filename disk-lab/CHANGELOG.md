# Disk Lab の更新履歴

公開版 https://shoji-mori.github.io/disk-lab/ の版。版は `app.js` の `VERSION` と `RELEASED` の一か所で決め、右の列の下端と
「このモデルについて」の末尾に小さく出す。新しい機能や物理の変更で二つ目の数を、小さな直しで三つ目の数を上げる。
設計の理由は DESIGN.md、エンジンの変更は engine/CHANGES.md。

| 版 | 日付 | 主な変更 |
| --- | --- | --- |
| 1.4 | 2026-10-17 | 描画が止まったときの「もう一度描く」、起動に失敗した理由の表示、ブラウザーの WebGL が使えない状態の案内、放っておかれたら時計を止めて GPU を休ませる、版の表示 |
| 1.3 | 2026-10-17 | 温度を物理から(照射の再放射、降着の加熱、熱電離した内側の粘性加熱、過熱される表層の塵)、消した成分は光も影も持たない、エンベロープの自然発光、惑星を 0.05 au から、惑星と周惑星円盤が光る、保存の解像度、静かに戻る画質、X 点の印と 1/4 カットの角度 |
| 1.2 | 2026-10-16 | 断面のラベルと凡例の作り直し、断面の量を温度・密度・領域に、塵をガスに含めて温度の構造を見せる、「可視光」、濃さのつまみを外す、既定の画質を最高に、Kanagawa et al. (2017) のギャップ、周惑星円盤 H/R = 0.1、サイトのヘッダーのリンク |
| 1.1 | 2026-10-16 | 時計の倍率を絵から外す、スノーラインの名前を遅らせる、流れの印を磁力線の設定へ、ヘッダーのホームへの印 |
| 1.0 | 2026-10-16 | /disk-lab/ で公開。サイトのカードからの遷移、動かしている間の解像度の切り替え |
